## 2. 色彩角色（实现时最容易做错的一条）

这是从四张主稿直接读出来的层级，不是「多色都重要」。

### 2.1 橘红 = 唯一主操作色

约 `#E65A00` / `#E8600F`（登录按钮、首页「查看我的项目」、详情「回到顶部」）。

用于：

- 所有实心主按钮：登录、搜索、新建文章、保存草稿、发布、添加标签、保存分类、返回首页、重试、下一页（主路径）
- 当前导航的**手绘下划线**（不是绿色胶囊填充）
- 标签描边与文字、列表右侧箭头、爪印品牌点
- 引用块左边条、部分强调字

登录按钮是主操作色的基准样本。搜索页、分页、后台，主按钮必须跟它同一块橘红，不能换成绿。

### 2.2 绿色 = 装饰 + 唯一信息性例外

约 sage `#5B7B5A`。在四张主稿里只出现在：

- 盆栽、叶子、小草
- 首页里个别次要标签（如「独立开发」）的淡绿字
- 详情页代码块顶栏 / 绿植，**不是按钮**

唯一信息性例外：后台状态芯片「**已发布**」用浅绿底 + 绿字（与所有后台稿一致）。除此之外绿色**禁止**用于：

- 整条顶栏背景
- 当前导航的实心胶囊
- 搜索按钮、放大镜圆形按钮
- 分页「下一页」
- 后台 FAB、保存、发布

图二（文章详情）里的绿，是绿植和代码窗装饰，不是「后台/搜索可以整页改绿」的授权。

### 2.3 其余

| 角色 | 约值 | 用途 |
|---|---|---|
| 纸底 | `#FBF6EE` / `#FDFBF7` | 全站背景，带轻微纸纹 |
| 卡片白 | `#FFFFFF` | 登录卡、侧栏、表格、表单卡 |
| 墨色 | `#1A1A1A` / 深棕 | 标题、正文 |
| 石色 | `#6B655C` | 摘要、元信息 |
| 芥黄 | `#D9A821` / `#F9D490` | 星星、搜索高亮、`最新发布` 选中底、归档状态、标签索引选中标签、分页当前页码 |

没有蓝、没有紫、没有深色后台皮肤。

## 3. 共享外壳

### 3.1 访客顶栏（C 端）

- 奶油底 + 底部分割线，不要色带。
- 左：橘猫头 / 爪印 + 「Leon 的博客」。
- 右：文章 · 分类 · 标签 · 搜索。
- 当前项：橘红手绘下划线 + 略加重的墨/橘色字。禁止绿胶囊。
- 角落允许一盆小绿植（装饰）。

### 3.2 后台顶栏（B 端）

登录页已经证明：后台入口也是奶油纸 + 橘红按钮，不是另一套绿皮肤。

因此后台顶栏与访客顶栏同一材质：

- 同样奶油底、同样墨色字、同样橘红下划线。
- 左：橘爪 + 「管理后台」。
- 中：概览 · 文章 · 分类 · 标签。
- 右：显示名、橘红文字链「查看站点 ↗」、描边胶囊「退出」。

若某张生成稿把后台顶栏画成橄榄绿条，视为模型偏差，**实现时丢弃绿条**，以本节为准。

### 3.3 页脚（C 端）

左：爪印 + `© 年 Leon 的博客 · 由热爱驱动`。  
右：手写感「保持好奇，持续创造。」+ 小星星。  
绿植只作小装饰。

### 3.4 涂鸦系统

橘猫姿势按页面分工，全部装饰、不承载信息：

| 场景 | 姿势 |
|---|---|
| 首页 Hero | 坐在笔记本旁 |
| 列表侧栏 / 登录卡顶 | 探头 |
| 分类页 | 坐着挑主题 |
| 标签页 | 伸懒腰 |
| 搜索 | 拿放大镜 |
| 空结果 / 空列表 | 睡觉 |
| 404 | 探头走丢 |
| 后台概览 | 挥手 |
| 编辑器 | 叼铅笔 |

另：爪印、四角星、波浪线、盆栽。动效最多轻微上下浮动；尊重 `prefers-reduced-motion`。

### 3.5 控件形状

- 主按钮、输入、筛选芯片：胶囊。
- 卡片 / 侧栏：大圆角（约 16–24px），细手绘感描边，几乎不用投影。
- 登录卡：更大圆角（约 40px），猫爪搭在上沿。

## 4. 按能力展开的页面（含补稿）

能力来自公开查询、搜索、分类/标签、认证、文章 `DRAFT | PUBLISHED | ARCHIVED`、分类/标签维护。下面每页只写布局与状态，不写旧组件类名。

### 4.1 已有主稿

**首页 `/`**  
作者定位 + 橘猫 Hero；「主要分类」图标卡；「最新文章」列表；侧栏「作品证据」+ 橘红「查看我的项目」。

**全部文章 `/posts`**  
标题「全部文章」+ 爪印。筛选条顺序：`所有分类` → `所有标签`（无 `#` 前缀）→ `最新发布/最受欢迎` 芥黄段控 → 搜索。左列表（日期 / **浅绿描边**分类胶囊 / 标题 / 摘要 / 橘红 `#标签` / 橘箭头）；右侧「热门标签」**实线白卡**，侧栏标签**不带 `#`** + 探头猫。

**文章详情 `/posts/[slug]`**  
面包屑；伸懒腰橘猫；标题与元信息；正文；橘红左边条引用；深色代码块（允许绿色只出现在代码窗装饰和语法高亮）；页边便签与绿植；橘红爪印回到顶部。

**登录 `/admin/login`**  
全屏奶油底；居中卡；探头猫；胶囊邮箱/密码（橘线框图标）；实心橘红「登录」。无注册。失败文案统一，不暴露账号是否存在。

### 4.2 访客补稿

**分类索引 `/categories`** → `redesign-categories-desktop.png`  
当前导航「分类」橘红下划线。标题「分类」。图标卡：手绘图标、名称、一句描述、篇数。卡片是**白底 + 实线描边**（`paper-card`），不要整卡铺绿，也不要虚线。

**分类下文章 `/categories/[slug]`** → `redesign-category-detail-desktop.png`  
「← 全部分类」橘红文字链；**左侧插画 + 分类名 + 描述 + 篇数**（无筛选行、无标题爪印）。列表节奏同文章页；侧栏「同类目录」实线卡，橘红描边胶囊（无 `#`，排除当前分类）。分页：描边「上一页」+「第 N/M 页」+ 实心「下一页」。无文章走空状态（睡觉猫）。

**标签索引 `/tags`** → `redesign-tags-desktop.png`  
标题「标签」。标签云：橘红描边胶囊（带 `#` + 篇数）；悬停浅橘底；**选中为橘红实心白字**。禁止绿胶囊导航。

**标签下文章 `/tags/[slug]`** → `redesign-tag-detail-desktop.png`  
「← 全部标签」；大号 `#标签名`；副信息「共 N 篇文章」；列表同文章页；分页：描边「上一页」+ 页码 + **实心「下一页」**。侧栏「相关标签」实线卡、标签**不带 `#`** + 探头猫。

**搜索 `/search`** → `redesign-search-desktop.png`  
标题「搜索」。宽胶囊输入 + **实心橘红「搜索」**（与登录按钮同色）。无词：引导输入。有词无结果：睡觉猫 + 「没有找到相关文章」+ 描边橘红「浏览全部文章 →」。有结果：芥黄荧光笔标出关键词；分页仅「上一页」（描边）+「下一页」（实心橘红），无页码方块。

**404** → `redesign-404-desktop.png`  
走丢的探头猫、**大号描边 404 数字**（页面最显眼元素）、实心橘红「返回首页」。

**空结果 / 系统错误** → `redesign-empty-error-desktop.png`  
空：虚线卡 + 睡觉猫 + 描边橘红胶囊「浏览全部文章 →」。错：同一气质，主按钮为实心橘红「**返回首页**」（重试可降为次级文字链），不是红底整页、也不是绿按钮。

### 4.3 后台补稿

后台与登录同一家族：奶油纸 + 橘红主按钮 + 橘猫。用「管理后台」文案区分身份，不用换皮成绿色控制台。

**概览 `/admin`** → `redesign-admin-dashboard-desktop.png`  
挥手猫；橘红「+ 新建文章」；三张白卡（文章 / 分类 / 标签数量）；「最近更新」表（标题、状态芯片、更新时间）。右下橘红 FAB `+`。

**文章列表 `/admin/posts`** → `redesign-admin-posts-desktop.png`  
状态芯片：全部（橘红实心为当前）/ 草稿 / 已发布 / 已归档。表：标题、状态、分类、更新于、编辑 / 预览 / 删除（**2026-09 产品确认：草稿与已归档文章可删，已发布需先归档再删**；删除确认引用服务器记录的标题与 Slug，有未保存输入时明确提示将丢失，二次确认）。

**编辑 `/admin/posts/new`、`/admin/posts/[id]/edit`** → `redesign-admin-editor-desktop.png`  
左：标题、摘要、Markdown（编辑 | 预览，当前 tab 橘红）。右：slug（曾发布则锁定）、分类、标签多选（选中橘红实心）、SEO 折叠。操作：橘红「保存草稿」、描边「预览」、橘红「发布」、弱化「归档」。草稿与已归档文章可删（已发布需先归档）。预览在新标签打开，观感接近 C 端详情，可加「预览中」条，不必另做视觉主题。

**分类管理 `/admin/categories`** → `redesign-admin-categories-desktop.png`  
表单（名称 / slug / 描述 / 排序）+ 橘红「保存分类」。列表带篇数、编辑、删除。删除不删文章，文章变为无分类，确认框写清影响篇数。

**标签管理 `/admin/tags`** → `redesign-admin-tags-desktop.png`  
名称 + slug + 橘红「添加标签」。标签云可编辑/删除。删除只拆关联，不删文章。

状态芯片（后台列表共用，**以 v2 像素稿为准**，2026-08 勘误：初稿误写为橘红/芥黄）：

| 状态 | 画法 |
|---|---|
| 草稿 | 奶油底 + 橘红描边与橘字（稿内实测 #FDF3D7 / #E5770B） |
| 已发布 | 浅绿底 + 绿字（稿内实测 #EEF2E1 / #476F1F，所有后台稿一致） |
| 已归档 | 浅灰底 + 灰字（稿内实测 #EFEDE5 / #9E9994） |

## 5. 响应式（稿以桌面为准，实现必须落到手机）

v2 桌面稿是构图源。手机不另做一套颜色。

- 顶栏：品牌 + 搜索图标 + 菜单；当前项仍用橘红，不用绿胶囊。
- Hero 大猫可在窄屏收起（纯装饰）。
- 双栏改为单列，侧栏热门标签/作品证据转到主列下方。
- 分类卡 2 列；后台表可横向滑，主按钮保持橘红胶囊。
- 触控目标 ≥ 44px。

## 7. 给后续改前端的约束

1. 先对稿，再写样式。不要沿用旧 class 里的 `leaf` 实心主按钮或绿顶栏。
2. Token 只需：纸底、表面、墨、石、橘红、橘红字、芥黄、sage（装饰）、危险色。sage 不进 Button 的 primary。
3. 主按钮在登录、搜索、新建、保存、发布、404 上必须是同一橘红。
4. 吉祥物只做 SVG 涂鸦，不靠照片；不对读屏复述。
5. 空 / 错 / 404 保持同一只猫的叙事，不要换成系统默认灰页。
