# Leon Blog 光标设计方案 · 橘猫爪印 v1

> 文档角色：自定义鼠标光标的**唯一设计事实来源**。
> 上游约束：`design/Leon-Blog-重设计方案-v2.md`（色彩角色、涂鸦系统、动效克制）。
> 本文只回答一个问题：用户在博客里移动、悬停、点击时，**看到的光标**长什么样、怎么变。

---

## 1. 一句话概念

光标是一只 28px 的手绘橘猫爪：

**平时侧着探路 → 摸到链接转正搭爪 → 点击像按下去一样回弹 → 在纸面盖一枚慢慢淡掉的爪印章。一进正文和输入框，立刻把 I 型光标还给系统。**

它是「贴在系统指针上的图形」，不是 `cursor: none` 之后的替身——系统箭头始终在，瞄准精度不受任何影响。

---

## 2. 光标本体规格

| 规格 | 值 |
|---|---|
| 画布 | 32 × 32 viewBox，导出 32 / 48 / 64 三档（高分屏用 2x） |
| 屏幕尺寸 | 28px；触屏与 `(hover: none)` 设备不渲染 |
| 填充 | 肉垫 `#F6A54B`；描边 `#2D1B0A` 1.5px；按压时肉垫加深 `#E65A00` |
| 热点 hotspot | `(10, 6)` —— 中间脚趾尖，点击精度等同系统箭头 |
| 默认姿态 | 逆时针侧倾 22°，像猫在探路 |
| 格式 | 内联 SVG（手帐涂鸦风），不做位图，避免高分屏模糊 |

配色全部取自 v2 方案 `DOODLE_COLORS`，不新增颜色。

### 爪形参考（实现时的 SVG 基准）

    <circle cx="7.4" cy="12.6" r="3" />
    <circle cx="13" cy="8.6" r="3.1" />

## 3. 五个状态

位移不超过 3px，缩放不超过 1.12，动画全部 ≤ 160ms。

| 状态 | 触发 | 形变 | 时长 |
|---|---|---|---|
| 默认 · 探路 | 纸底、装饰、不可点区域 | `rotate(-22°)`，无位移 | 常驻 |
| 悬停 · 搭爪 | 链接、按钮、卡片、标签、导航 | `rotate(0°)` + `scale(1.12)`，肉垫 `#F6A54B → #E65A00` | 150ms ease-out |
| 按下 · 按爪 | `mousedown` / `touchstart` | `scale(0.88)`，像猫爪真正按下去 | 120ms |
| 点击 · 落印 | 每次有效点击 | 点击坐标盖半透明爪印，随机 ±12° 旋转，`scale 0.6→1` 后淡出 | 总计 550ms |
| 文本 · 归还 | `.post-prose`、`input`、`textarea`、代码块 | 自定义爪隐藏，系统 I-beam 接管 | 立即 |

状态转移：`默认 ⇄ 悬停 → 按下 → 落印 → 回到悬停/默认`；命中文本区时任何状态立即让位给系统光标。

## 4. 落印：唯一的彩蛋

点击落印是这套光标唯一的动效彩蛋。它发生在**点击点**、不在光标本体上，所以不影响瞄准。

| 参数 | 值 |
|---|---|
| 爪印尺寸 | 20px，opacity 0.35 |
| 生命周期 | 出现 80ms → 停留 220ms → 淡出 250ms |
| 旋转 | 每次随机 -12° ~ +12°，像真的踩出来 |
| 同屏上限 | 最多同时存在 3 枚，超出立即回收最旧的 |

不做移动拖尾——爪印串会弄脏阅读页。

---

## 5. 在哪里生效

| 区域 | 爪印光标 | 落印 | 说明 |
|---|---|---|---|
| 首页 / 文章列表 / 分类 / 标签 / 搜索 | 开 | 开 | 浏览页，是彩蛋的主场 |
| 文章详情 | 开 | 开 | 但 `.post-prose` 正文内一律恢复系统光标 |
| 404 / 空状态 | 开 | 开 | 和走丢的猫最搭 |
| 登录 / 后台 / 编辑器 | 关 | 关 | 工作区讲效率，保持系统光标，只保留纸面 hover 配色 |
| 任何 `input` / `textarea` / 代码块 | 强制关 | 强制关 | 命中检测，不设例外 |
| 触屏设备 | 关 | 关 | `(pointer: coarse)` 直接不加载 |

---

## 6. 硬性约束

**必须做到**

1. 系统光标永远不隐藏：自定义爪是贴在指针上的图形，不是 `cursor: none` 后的替身。
2. `prefers-reduced-motion` 时：落印和形变全部关闭，只留静态爪形（也可整体退回系统光标）。
3. 启用条件：`(hover: hover) and (pointer: fine)` 同时满足。
4. 命中检测实时进行：指针进入文本区 / 输入框的同一帧内让位系统光标。

**明确不做**

- 不做移动拖尾。
- 不做自定义 I 型光标，不替换任何文本区光标。
- 不在后台和表单页启用——那里是工作区，不是手帐。
- 不引入动画库：一个组件 + 少量 CSS transition 就够。

---

## 7. 验收口径

- 桌面 Chrome / Safari / Firefox：默认见侧倾爪、悬停转正加深、按下回弹、点击落印并淡出。
- 进入正文与输入框立刻恢复系统 I-beam。
- 系统开启「减少动态效果」后无任何动画。
- 触屏设备完全不出现。
- 后台与登录页保持系统光标。
